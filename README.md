# NaoTube

Client YouTube pour **Android TV / Google TV**, sans publicité, avec SponsorBlock et une interface noire et rouge pensée pour la télécommande.

> Projet personnel, en cours de construction.

## Installer sur la TV

1. Sur la TV, installe l'appli **Downloader** (Play Store).
2. Dans Downloader, tape l'adresse :
   `https://github.com/Naofel69rlp/NaoTube/releases/latest/download/NaoTube.apk`
3. Accepte l'installation (Android te demandera une fois d'autoriser Downloader).

Ensuite, NaoTube se met à jour tout seul : **Réglages → Mises à jour**.
